# ORAC Holding Website

Premium React + Vite website for ORAC Holding and its business verticals.

## Routes

- `/`
- `/international`
- `/eventus`
- `/luxury-export`
- `/evolution`
- `/contact`

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Notes

Image locations are centralized in:

- `src/data/internationalImages.js`
- `src/data/eventusImages.js`

Current visual slots are intentionally prepared as premium placeholders so final brand images can be added without touching component structure.
